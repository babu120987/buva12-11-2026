Deals

A deal lowers a product's price between the start and end time, with a countdown on the store. The original price returns automatically when the deal ends or you cancel it. Don't edit that product's price in the main admin while its deal is running.

Combo offers

Applied automatically in the bag when the shopper has enough items, e.g. "Buy any 2, save 10%". Only the best combo applies. If it isn't stackable and a coupon is entered, the shopper gets whichever saves more.

Coupons shown in the bag

Coupons are created in the main admin under Marketing. Here you choose which ones shoppers see listed in their bag (with one-tap Apply), and the line of text shown under each.

Photos & sizes

Photos: upload several photos per product for the zoomable gallery. The first photo is the main image. Sizes: to sell one perfume in several sizes (30 / 50 / 100 ml), create each size as its own product in the main admin with its own price and stock. Then give them all the same size group here, e.g. madurai-jasmine.

Review photos

Photos customers attach to reviews. They appear on the store only after you approve the review (main admin → Reviews & support). Delete any photo that isn't suitable.
